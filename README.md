# Karthik Chandrasekaran - Personal Website

Personal branding site for engineering leadership, technical writing, research, and selected projects. Built with Astro and deployed to GitHub Pages.

## Development

```sh
npm install
npm run dev
```

Update profile content in `src/data/site.ts`. Pages and shared layout live under `src/pages` and `src/layouts`.

## Deployment

Pushes to `main` deploy automatically through `.github/workflows/deploy.yml`.
